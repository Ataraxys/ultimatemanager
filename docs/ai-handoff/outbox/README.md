# Outbox — ChatGPT → Codex

ChatGPT places mission instructions, architecture decisions, review requests, and explicit approvals here.

Codex agents must:
- inspect the latest relevant instruction before starting;
- follow the scope and prohibitions exactly;
- not assume that the presence of an instruction file authorizes work beyond its stated mission;
- report blockers instead of silently changing scope.

Use unique filenames. Do not overwrite previous mission instructions.
